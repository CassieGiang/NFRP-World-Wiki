Augmentation rituals C/B/A/S

C/B/A/S-rank passive. Permanent body changes (claws, hides, extra arms...) and curses for enemies. Each rank lets the ritualist write that rank's ritual seals at the scribe desk.

Passive (always on, no button)

Learn at class level C 5, B 9, A 13, S 18
